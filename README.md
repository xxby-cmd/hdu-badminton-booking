# 杭电场馆预约助手

在 Windows 上选择场馆、日期和时段，设置定时预约。支持羽毛球和网球、手动登录或可选的钉钉自动登录。

## 1. 下载并启动

需要 **Windows 10/11 64 位（Intel / AMD）**、网络和电脑版钉钉，并已获得学校场馆系统的预约权限。

1. 本页点击 **Code → Download ZIP**，完整解压到一个固定文件夹；也可以克隆本仓库。
2. 双击 **`启动预约助手.cmd`**。
3. 首次启动会检查环境。没有可用环境时，自动解压仓库自带的约 13 MB 运行环境并完成配置，然后打开助手。不需要手动安装 Python、配置 PATH 或执行构建命令。

后续仍双击这个入口即可；也可双击 `启动预约助手.vbs`，正常启动不保留命令行窗口。代码包已带运行环境，首次准备也不需要再下载；不会修改系统 Python 或 PATH。

请先安装并运行 [电脑版钉钉](https://www.dingtalk.com/)。请勿直接在 ZIP 压缩包内运行，也不要在设置好定时计划后移动文件夹。

## 2. 首次设置登录

首次打开会显示“开机与登录设置”，之后可随时从主界面底部再次打开。

- **手动登录**：不勾选自动登录授权，不填写账号密码，点击“保存设置”；在钉钉中本人完成登录并进入场馆首页，然后刷新排期。
- **自动登录**：确认检测到的钉钉位置，勾选本机授权，填写自己的账号密码，点击“保存并测试登录”。助手会尝试登录并打开场馆入口。验证码、扫码或设备确认需本人完成。
- **开机启动**：按需勾选“登录 Windows 后自动运行预约守护程序”；不勾选则自己打开助手。这个选项随时可以关闭。

账号密码只加密保存在当前 Windows 用户的电脑上，不会上传到 GitHub。换电脑需要重新设置登录和计划，不要复制他人的登录资料。

## 3. 选择并安排预约

1. 选择运动场馆，点击“刷新七天排期”。
2. 选择日期，再点击场地和时间格子，每天同一场馆最多两个时段，不能与本人已有预约或受邀时间冲突。
3. 点击“设为定时启动”。看到“已登记定时启动”和具体时间，表示计划已保存。

当前按学校放场时间安排：**使用日期前两天19:00启动准备，20:00尝试预约**，以界面显示的具体日期、时间为准。例如预约周三，通常周一19:00准备、20:00提交。也可点“开始所选计划”提前打开程序等待放场。

请在计划启动前开机并登录 Windows，保持联网且不要休眠。开机自启不能让关机或休眠的电脑自行开机。学校登录过期时可能需要重新验证；看到“正在等待放场”才表示准备检查已通过。

## 4. 修改或删除计划

- **蓝色**：当前已保存的有效计划。
- **橙色**：新选择、尚未保存的格子。
- **浅黄色**：可点击重新选择的格子。
- **灰色**：当前不能选择。

改选时，原计划继续显示蓝色并保持有效。最多选两格；选满后再点击其他时间，会从该格重新开始选择。确认整体替换并保存成功后，新计划才变蓝，旧计划才退出。原计划的格子也加入新选择时，会显示蓝底橙色圆点。

右侧“更改计划”可载入原计划重选，“删除计划”会停用尚未启动的本地任务。删除本地计划**不会取消学校订单**。已停止和失败的记录保留在历史中，不再占用选格名额。

## 5. 预约成功后

成功后请及时到钉钉核对“我的预约”，并在学校要求的 **10分钟内至少邀请一位同伴**，否则学校可能自动取消。助手不代替你邀请同伴或取消订单。

助手可点叉收进系统托盘，点击托盘图标恢复。场馆网页在登录验证完成后可关闭，后台预约不依赖它一直显示；后续登录失效时可能需要重新打开。钉钉消息提醒不能代替有效订单核验。

## 常见问题

- **准备环境失败**：确认完整下载并解压了整个仓库，保留 `runtime` 文件夹，再次双击启动。若缺少自带环境，入口会尝试从本仓库 Releases 下载，请保持网络可访问 GitHub。
- **钉钉没有自动登录**：先确认在“开机与登录设置”中保存了账号密码并授权；查看钉钉是否要求验证码或设备确认。自动准备最多检查10轮，结果不明时不会反复提交密码。
- **换电脑使用**：重新下载或克隆，双击启动，重新设置自己的登录和计划即可。
- **预约助手打开了但没启动计划**：到“历史记录 / 更改场地”检查是否已登记定时任务，以及具体启动时间。
- **能保证抢到吗**：不能。是否成功取决于学校开放情况、名额、网络和服务器响应，请以学校订单为准。
