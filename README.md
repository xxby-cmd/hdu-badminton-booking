## 本地使用

1. 安装 Windows Python 3.11 或以上版本，包含 Tkinter，并确保 `pythonw.exe` 在 PATH 中；程序仅使用标准库。
2. 保持电脑钉钉登录，在浏览器打开 `钉钉场馆入口.html`，点击按钮进入钉钉自己的场馆窗口，确认显示本人姓名。
3. 修改后先运行下方离线仿真。网球入口`tennis_test.py`默认也只仿真；本次带`--live-once`的单次真实验证已执行完毕，持久记录禁止再次重跑。
4. 原羽毛球计划若另获执行授权，其窗口“已就绪，等待放场”仅表示只读预检已通过。创建待邀请订单后，仍须十分钟内邀请至少一名同伴，否则学校会自动取消。

每次执行前需确认登录有效期覆盖执行时间。当前适配钉钉的`DingTalk_133`浏览器数据目录；生产读取已用标准库根据CURRENT/MANIFEST确定活动SST和WAL，核对CRC32C、Snappy压缩、块内前缀及重启点，按序列号合并并保留删除；不扫描过期表复活旧身份，不写入或锁定钉钉数据库，源变化最多重读三次。

原字符串类型保持不变，缓存仅用Windows DPAPI加密并原子保存。明确注销、无效新会话、账号切换或损坏数据不会被旧缓存掩盖；只有源确实不可读或没有登录资料时，才允许完整、身份和期限可验证的既有缓存退路。换电脑或钉钉升级仍需重新核验兼容性。

## 速度和结果判断

完整放场前复查提前至放场前一分钟；最后三秒仅做短超时校时，不再把默认五秒网络等待放在最后一秒。近期低往返延迟的校时锚点不会被明显更慢的末次样本替换。明确只读查询遇到临时连接错误最多重连一次；准备阶段的临时网络错误及只读502/503/504可在原期限内最多进行三轮准备，认证及业务失败仍停止。

时段映射、候选和请求正文在放场前准备。每份新库存只扫描一次场地，复用已编译的时段位图；放场后的正常首单流程仍为 `creat_book_info` → `creat_order` →“我的预约”核验。只有HTTP 200明确返回的冲突才记入对应场地时段，跳过包含相同冲突的组合，先使用已有合法候选，无需每次再查一次库存。候选耗尽或放场前尚未开放时，最多刷新空位三次；仍以完整两小时优先，只退让原定两种单小时。

全部请求串行，明确冲突回复后保留25ms冷却，空位刷新另按120/240/360ms退避，不把第三方间隔当作学校限流阈值。单轮最多校验36个不同候选，并受原20秒期限限制；保留上限以覆盖12片场地及两种退让，不因只试满12次就漏掉单小时。未知500、验证码、401/403、业务拒绝及不完整的校验回复不会触发自动写请求重发；校验异常会立即显示诊断状态，只读核对本人、受邀订单和空位，记录脱敏原因。校验、创建和取消请求均不在网络层自动重发。

普通状态和事件日志由单个后台线程顺序写入，界面先更新内存状态，抢场活动及放场前后三秒按50ms检查界面状态，平时500ms。后台写盘错误会明确显示并禁止新的订单提交；退出时等待工作线程和日志排空。防重复持久记录仍同步写盘，不为了速度省略保护。

默认尝试窗口仍为原放场后20秒。明确授权的故障恢复可传入带时区的 `recovery_until`，最晚不超过原放场后30分钟；原放场时间、费用、目标时段及防重复标记不变。运行中的旧进程不会自动加载磁盘修复，不能把保存修复说成已部署。

提交没有得到明确回复时先查订单，不重复创建。原窗口在最后校时后、等待放场前预写`validation-日期.json`校验意图，创建前仍写原`submitted-日期.json`；任一标记存在都会阻止重启再提交。标记可能在真正发请求前已经写下，这是保守的防重复行为，不表示学校已创建订单，也不自动清除以恢复机会。当前已消费的网球一次测试记录保持原样。无法核实的结果会显示“请到钉钉核对结果”。成功核对必须匹配日期、场馆、项目、时段、场地、订单号及费用；原羽毛球流程不自动取消订单，网球单次验证只取消自己新建、核实并已邀请的精确订单。

初版提交 `8cb2809` 在2026-11-03的测量结果见 `benchmark-results.json`，不代替修订版的真实预约验收：

- 本地模拟 5,000 次，接口立即返回：中位数 0.024 ms，P95 0.0262 ms。
- 加入防重复记录落盘后模拟 200 次：中位数 5.1349 ms，P95 6.1609 ms；不包含网络、学校处理和窗口日志写入。
- 保持连接的真实只读请求，各测 5 次：服务器时间查询中位数 11.622 ms，场馆信息查询 40.075 ms，本人订单查询 66.656 ms；首次冷连接时间查询 332.041 ms。

这些是非高峰数据，不能当作下单耗时；尚未测量手动预约基线。真实执行会记录放场到首次请求、到订单回复、到订单核实的时间，便于实测比较。
