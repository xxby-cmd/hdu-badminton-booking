# 杭电羽毛球预约助手

Windows 本地运行，使用本人已登录的钉钉场馆会话。当前版本已通过模拟测试和本人账号的只读查询验证；尚未实测真实预约成功率和放场时的提交速度。

| 计划 | 执行时间（北京时间） | 预约日期 |
| --- | --- | --- |
| 周四测试 | 2026-11-03 20:00 | 2026-11-05，周四 |
| 周五正式 | 2026-11-04 20:00 | 2026-11-06，周五 |

两套计划都优先选择任意同一片场地的 **19:00–21:00**；完整两小时不可用时，尝试 **19:00–20:00** 或 **20:00–21:00**。每次计划只创建一笔订单，费用上限为 ¥0。邀请同伴、取消预约由本人在钉钉手动处理。

## 使用

1. 安装 Windows Python 3.11 或以上版本，包含 Tkinter，并确保 `pythonw.exe` 在 PATH 中；程序仅使用标准库。
2. 保持电脑钉钉登录，在浏览器打开 `钉钉场馆入口.html`，点击按钮进入钉钉自己的场馆窗口，确认显示本人姓名。
3. 双击对应的 `打开今晚试约.cmd` 或 `打开明晚正式预约.cmd`。窗口显示“已就绪，等待放场”才算准备成功。
4. 保持电脑开机联网、保留运行窗口。成功后十分钟内到钉钉手动邀请同伴。

明天正式预约前需重新确认登录；今天的登录有效期不覆盖明天。当前适配钉钉的 `DingTalk_133` 浏览器数据目录。程序只从场馆网站的本机存储记录中读取会话，使用 Windows DPAPI 加密缓存。换电脑、钉钉升级或登录记录已压缩时，可能需要重新登录或调整数据目录。

## 速度和结果判断

放场前完成账号、本人订单、场馆信息、时段和服务器时间检查。放场后的正常首单流程为 `creat_book_info` → `creat_order`，随后读取“我的预约”核验。网络连接保持复用；场地冲突时重新读取空位并尝试下一选项。总尝试时间和请求次数有上限。

提交没有得到明确回复时先查订单，不重复创建。提交前写入一次性记录，重启程序也不会重新发出创建请求。无法核实的结果会显示“请到钉钉核对结果”。本工具不会自动取消已有订单。

2026-11-03 的测量结果见 `benchmark-results.json`：

- 本地模拟 5,000 次，接口立即返回：中位数 0.024 ms，P95 0.0262 ms。
- 加入防重复记录落盘后模拟 200 次：中位数 5.1349 ms，P95 6.1609 ms；不包含网络、学校处理和窗口日志写入。
- 保持连接的真实只读请求，各测 5 次：服务器时间查询中位数 11.622 ms，场馆信息查询 40.075 ms，本人订单查询 66.656 ms；首次冷连接时间查询 332.041 ms。

这些是非高峰数据，不能当作下单耗时；尚未测量手动预约基线。真实执行会记录放场到首次请求、到订单回复、到订单核实的时间，便于实测比较。

## 验证

```powershell
python -m unittest discover -s tests -v
python benchmark.py
python benchmark.py --read-only-network
```

模拟覆盖完整两小时、两种一小时退让、优先级、冲突、登录失败、网络异常、订单核实、防重复及执行日期。`benchmark.py` 的真实请求仅限只读查询，不创建或取消预约。

运行状态、登录缓存、订单号和防重复记录保存在 `.private/`，由 `.gitignore` 排除。仓库包含代码、模拟测试和不含个人信息的性能结果。
